# Processed training data

This folder contains small, reviewable artifacts used by the prototype:

- `physiology_training.txt` contains sentence-level language patterns and
  physiology context for retrieval and the word-level demo.
- `physiology_cards.json` contains structured question/answer facts that are
  preferred for precise study responses.

Future preprocessing can write cleaned textbook sections here while keeping
the original notes in `data/raw`.
